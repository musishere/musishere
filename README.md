## 🎮 Khel — marketplace booking platform

Co-founder, backend & systems. Go (`chi` / `fiber`).

- Reservation engine handling booking conflicts, payment deadlines and partial payments
- Peer-to-peer split-payment system built in-house, replacing the third-party gateway — lower transaction cost, one less external dependency
- ELO-based matchmaking with ratings, badges and streaks for retention
- Real-time communication across bookings and matches, aimed at the drop-off points that actually cost users

## 🧾 Invoice Data Extraction Pipeline — OCR + LLM

PaddleOCR → LangGraph → validated structured JSON.

- PaddleOCR front end that survives varied layouts, fonts and poor scan quality
- LangGraph workflow with graph nodes for extraction, validation, and error-correction / retry
- Schema validation that catches and self-corrects low-confidence extractions *before* anything is persisted
- Replaces manual invoice entry end to end: vendor, line items, totals, tax, dates

## 📊 Data & BI Platform

End-to-end build — backend, frontend, infra.

- Node.js / Express / PostgreSQL backend aggregating pipeline metrics into real-time sales, ROI and inventory reporting
- React dashboard with visualizations, inventory health monitoring and drill-down reporting
- Auth and role-based access control over sensitive sales and ROI data
- Real-time visibility that helped scale daily revenue ~3–3.5x ($2K/day → $6–7K/day)
